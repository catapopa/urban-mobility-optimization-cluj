# Urban Mobility Optimization in Cluj-Napoca

This project uses Complex Networks and Optimization Techniques to improve the efficiency of public transport routes in Cluj-Napoca, Romania.

## Goals

- Model the Cluj public transportation network as a graph
- Analyze weaknesses using network theory
- Apply optimization algorithms to improve routing and coverage
- Visualize and evaluate results

## Structure

- `data/`: Raw and processed data sources (GTFS, OSM, population density)
- `notebooks/`: Data exploration and graph analysis notebooks
- `src/`: Python modules for graph construction, optimization, and analysis
- `results/`: Generated visualizations and evaluation data
- `thesis/`: Final write-up
